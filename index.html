PROYECTO 01 · AUTOMOTRIZ / TELEMETRÍA SDV & GESTIÓN ITIL v4
Arquitectura IBN · DoIP/UDS + Power BI (DAX)

SDV-IBN Tooling & Telemetry Hub

Ecosistema integral de puesta en marcha electrónica (Inbetriebnahme — IBN) para vehículos definidos por software (SDV), diseñado para asegurar la trazabilidad diagnóstica en línea de producción, tolerancia a fallos y visibilidad ejecutiva en tiempo real.

  • Gateway Diagnóstico & Seguridad: Integración de un gateway TCP DoIP/UDS con middleware en Python (Flask) e inspección de integridad mediante validación CRC32 / PKI.
  • Terminal Andon & Fault Injection: Interfaz web en tiempo real (Bootstrap 5) con módulo de simulación de fallos de planta (Fault Injection) para pruebas de estrés operativo.
  • Automatización ITIL v4 en Base de Datos: Procedimientos almacenados y triggers en PostgreSQL (PL/pgSQL) para detección automática de paros de línea críticos (P1), sugerencia de workarounds y conmutación automática (failover) a servidor espejo.
  • Analítica Industrial en Power BI (DAX): Tablero ejecutivo para monitorear First Time Quality (FTQ), Takt Time vs. Ciclo Real, diagrama de Pareto de códigos de falla (DTCs) y MTTR.

-- Trigger PL/pgSQL: Detección automática de incidente P1 (ITIL v4)
CREATE OR REPLACE FUNCTION fn_handle_sdv_line_stop()
RETURNS TRIGGER AS $$
BEGIN
  IF NEW.dtc_severity = 'P1_LINE_STOP' THEN
    INSERT INTO itil_incidents (vin, dtc_code, priority, workaround_id, mirror_switched)
    VALUES (NEW.vin, NEW.dtc_code, 'P1', get_best_workaround(NEW.dtc_code), TRUE);
    PERFORM pg_notify('andon_alert_channel', NEW.vin || ':FAILOVER_MIRROR');
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
PROYECTO 02 · DATA ENGINEERING / PIPELINE ELT & MODELADO DIMENSIONAL
Ver Repositorio en GitHub (TamerNarciso/PipelineELT) ↗

Pipeline ELT de Datos Financieros con Airflow, dbt y PostgreSQL

Arquitectura ELT por lotes contenerizada en Docker que extrae diariamente precios históricos OHLCV de acciones y tipos de cambio oficiales del Banco Central Europeo, almacena datos crudos con idempotencia garantizada y construye un modelo dimensional analítico con dbt.

  • Ingesta Idempotente & Ventana Deslizante: Paquete Python 3.11 (yfinance, requests) que ejecuta INSERT ... ON CONFLICT DO UPDATE con reprocesamiento de 7 días para absorber feriados y ajustes tardíos sin duplicar registros.
  • Transformación Modular en dbt-core: Capas staging (tipado y limpieza), intermediate (forward-fill de divisas en fines de semana y conversión multimoneda genérica) y marts (dim_ticker, dim_date, fct_daily_prices incremental, fct_returns con SMA 7/30 y volatilidad anualizada).
  • Orquestación & BI como Código: DAG diario en Apache Airflow 2.10 con entornos virtuales aislados, suite de pruebas con pytest, ruff, GitHub Actions CI y aprovisionamiento automatizado de 11 consultas y dashboard en Metabase vía API.

-- Consulta analítica sobre el modelo dimensional construido con dbt
SELECT
    p.ticker,
    t.company_name,
    p.as_of_date,
    ROUND(p.return_ytd * 100, 2) AS return_ytd_pct,
    ROUND(r.volatility_30d_annualized * 100, 2) AS vol_30d_pct
FROM marts.agg_ticker_performance p
JOIN marts.dim_ticker t USING (ticker)
JOIN marts.fct_returns r
  ON r.ticker = p.ticker AND r.trade_date = p.as_of_date
ORDER BY p.return_ytd DESC;
